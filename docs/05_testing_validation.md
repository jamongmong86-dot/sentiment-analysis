## 1. 기능 테스트 케이스

### 1.1 입력 유효성 검증
| 테스트 ID | 테스트 시나리오 | 입력값 | 예상 결과 | PASS/FAIL |
| :--- | :--- | :--- | :--- | :--- |
| TC-01 | 공백 및 1자 입력 | `" "` 또는 `"아"` | "2자 이상 입력해주세요." 오류 메시지 표시 |  |
| TC-02 | 정상 긍정 텍스트 | `"오늘 합격 소식을 들어서 행복해요!"` | 긍정, 신뢰도 > 80%, 이유 출력 |  |
| TC-03 | 정상 부정 텍스트 | `"배송도 늦고 제품이 부서져서 화가 납니다."` | 부정, 신뢰도 > 80%, 이유 출력 |  |
| TC-04 | 정상 중립 텍스트 | `"지하철 2호선 운행 시간표입니다."` | 중립, 이유 출력 |  |
| TC-05 | 1,000자 초과 입력 | 1,001자 텍스트 | 입력 제한 경고 및 요청 블로킹 |  |

## 2. 오류 처리 검증 (Error Handling)
- **API Key 누락**: `.env`에 OpenAI Key가 없을 경우 `500 Internal Error` 및 사용자 친화적 오류 문구 화면 노출.
- **네트워크 장애**: 인터넷 연결 끊김 시 "네트워크 연결 상태를 확인해주세요." 표시.
